What installing triib changes

triib goes into Applications. So that it can reach AVB and Milan devices, and run this Mac's own entities, without running as an administrator, installing it also:

  • adds you to the access_bpf group, creating it if it is not there yet, the same group Wireshark uses;
  • installs a launch daemon, run.triib.bpf, which at every start lets that group open the Mac's packet capture devices (/dev/bpf*), so triib can send and receive AVB's own network frames;
  • links triib-cli, triib's command line tool, into /usr/local/bin.

Nothing else on the system changes. To take triib and the launch daemon out again, run sudo "/Library/Application Support/triib/uninstall". The access_bpf group stays, as other apps may use it.
